# Afterglow documentation

Afterglow is a locally hosted AI companion. It builds retrievable memories and a persona from real chat history, and serves conversations through an OpenAI-compatible API.

> The documentation website and GitHub Wiki are generated from this repository. Edit `docs/en/` and the corresponding Chinese pages in `docs/wiki/` through a pull request. Do not edit the Wiki directly.
