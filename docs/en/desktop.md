# Afterglow Desktop

[Afterglow Desktop](https://github.com/kldhsh123/Afterglow-Desktop) is the Windows desktop client for Afterglow.

## Features and runtime

The application bundles the original Afterglow core and a portable Python runtime. It brings the following into one interface:

- Setup wizard
- Model connections
- Chat history import
- Chat and analysis

## Configuration and data

Separate installation directories can each keep their own configuration and data.
