# 常见问题

**Q：什么是"配置向导"？必须用吗？**
A：可选但推荐首次使用。后端缺少关键配置时会自动启用 `/config/`，终端打印一次性 token；
浏览器完成 8 步即可写入 `.env`、导入聊天并生成 persona。手动流程见
[快速开始](快速开始.md#手动配置)。

**Q：必须用阿里云 Qwen3-Embedding 吗？**
A：不必，任何 OpenAI 兼容的 `/embeddings` 接口都可以。改 `EMBEDDING_API_URL` / `EMBEDDING_MODEL` / `EMBEDDING_DIM` 即可。本地 ollama 也支持。已经导入过数据后再换模型，需要重建向量库，见[故障排查](故障排查.md#导入报-spill-has-sent-an-error)。

**Q：必须用 OpenAI 吗？**
A：不必。主模型支持 OpenAI 兼容的 Chat Completions 和 Responses 上游协议；通过 `CHAT_API_PROTOCOL=chat_completions` 或 `responses` 选择。DeepSeek、Moonshot、Qwen、ollama 等通常使用 Chat Completions，具体以服务商支持的端点为准。

**Q：能不能不脱敏 PII？**
A：可以。`.env` 设 `ENABLE_PII_REDACTION=false`，或通过 `PII_RULES_PATH` 加载自定义规则。

**Q：QQ 号 / URL 为什么不脱敏？**
A：QQ 号在导出文件里到处都是（uid 关联需要）；URL 是对话语境的一部分（朋友分享 B 站视频是有意义的）。脱敏列表只覆盖一旦泄漏就造成实质损失的"硬隐私"。

**Q：能否导入微信 / Telegram / Discord 数据？**
A：QQ 推荐使用 QQChatExporter。微信可使用第三方开源工具 [WeFlow](https://github.com/hicccc77/weflow) 导出的 `arkme-json` 或 `ChatLab JSONL`。Telegram Desktop HTML、DiscordChatExporter JSON、WhatsApp TXT/Markdown 已内置支持。其它平台可以通过 ingestion plugin 扩展。

**Q：会不会越聊越不像？**
A：每轮对话都会异步回写到 `live_messages`（`trust_level=0.35`，权重远低于历史 `1.0`）。前端可在设置页"暂停回写"避免污染。

**Q：怎么删除某条记忆？**
A：调 `DELETE /memory/friend_messages/{chunk_id}` 或 `DELETE /memory/response_pairs/{pair_id}`（软删除）。

**Q：能本地完全离线吗？**
A：可以。LLM 用 ollama / vLLM；embedding 用 `nomic-embed-text` / `bge` 等本地模型。

---

**Q：为什么后端语言与页面不同？**
A：页面与后端语言独立。后端设置 `XUWEN_LANGUAGE=en|zh-CN` 后重启；CLI 使用 `--language`、HTTP 使用 `Accept-Language` 覆盖各自输出。主动消息始终用后端语言，旧聊天和已保存报告不自动翻译。
