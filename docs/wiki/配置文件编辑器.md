# 配置文件编辑器

在浏览器中生成或修改后端 `.env` 文件。交互编辑器位于[文档网站](https://kldhsh123.github.io/Afterglow/zh/config-editor.html)，不依赖已经运行的后端，也不需要配置 UI 的访问 token。

## 使用编辑器

1. 从模板默认值开始，或导入现有 UTF-8 `.env` 文件。导入会替换当前草稿，保留未知变量；原有注释会在导出时替换为当前语言的注释。
2. 填写双方名字和账号 UID、聊天服务、向量服务及后端访问密钥。身份信息应从导出的聊天记录中确认。服务地址填写供应商的基础地址，保留其要求的 `/v1` 等路径，不带 `/chat/completions` 或 `/responses` 后缀。
3. 切换到全部配置，通过分组或变量名搜索调整高级选项。说明与模板默认值来自[环境变量参考](后端环境变量.md)。文件模板采用后端默认值，与英文配置向导的服务建议有所不同。
4. 下载 `.env`，放到 `backend/.env` 后完全重启后端。覆盖已有配置前请先备份。进程环境变量的优先级高于文件中的值。

文件处理都在当前标签页完成。填写的值不会提交到服务器、写入浏览器存储或进入页面 URL。在站内切换语言会保留草稿，只改变说明和导出注释；刷新或关闭标签页会丢弃草稿。后端语言通过独立字段 `XUWEN_LANGUAGE` 设置，默认 `en`，切换编辑器界面语言不会修改它。

密钥字段和生成文件预览默认隐藏。下载文件包含真实密钥。基础检查覆盖字段类型、显式数值范围及部分配置联动，完整校验在后端启动时进行。必填项留空可保存为草稿。导入的 `${VARIABLE}` 表达式会原样保留，交给后端展开。

## 下载模板

如果无法使用 JavaScript，可下载以下任一模板并复制为 `backend/.env`。两份模板的变量和值完全一致，仅注释语言不同。

- [英文注释：.env.example](https://github.com/kldhsh123/Afterglow/blob/main/backend/.env.example)
- [中文注释：.env.example.zh-CN](https://github.com/kldhsh123/Afterglow/blob/main/backend/.env.example.zh-CN)

需要鉴权连接检查、导入聊天记录或直接在后端写入配置时，请使用[配置向导](快速开始.md)。
