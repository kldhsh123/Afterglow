# Afterglow Desktop

[Afterglow Desktop](https://github.com/kldhsh123/Afterglow-Desktop) 是 Afterglow 的 Windows 桌面端。

## 功能与运行环境

程序自带原版 Afterglow 核心和便携 Python，将以下功能整合到一个界面：

- 配置向导
- 模型连接
- 聊天记录导入
- 聊天与分析

## 配置与数据

不同安装目录可以分别保存配置和数据。
