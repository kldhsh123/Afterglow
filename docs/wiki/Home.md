# Afterglow 文档

Afterglow（续温）是一个本地运行的 AI 朋友系统。它从真实历史聊天中构建检索记忆和 persona，
通过 OpenAI 兼容 API 提供聊天能力。

> 本目录是项目文档的唯一真源。GitHub Wiki 由 Actions 自动同步，请通过修改
> `docs/wiki/` 并提交 PR 来更新文档，不要直接编辑 Wiki 页面。
