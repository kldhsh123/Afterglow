# Afterglow 文档

Afterglow（续温）是一个本地运行的 AI 朋友系统。它从真实历史聊天中构建检索记忆和 persona，
通过 OpenAI 兼容 API 提供聊天能力。

> 主要阅读入口是 [双语文档网站](https://kldhsh123.github.io/Afterglow/)。中文源位于 `docs/wiki/`，英文源位于 `docs/en/`，网站与 Wiki 均由仓库生成。请通过 PR 更新两种语言，不要直接编辑 Wiki。
